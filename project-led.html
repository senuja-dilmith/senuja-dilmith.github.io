Project Overview

The Automatic Brightness Control LED System was created to dynamically adjust lighting intensity based on ambient brightness and occupancy conditions. This concept emphasizes energy efficiency, user comfort, and practical automation in everyday spaces.

By combining sensing with decision logic, the project demonstrates how smart control systems can reduce wasted energy while keeping lighting performance responsive and useful in real-life environments.
